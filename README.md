# 💰 Personal Finance Tracker (Fintech Dashboard)

## 🔍 Project Description

Personal Finance Tracker is a **modern fintech-style web application** built using React, Firebase, and Tailwind CSS. It allows users to securely manage their income and expenses, analyze financial trends, and visualize spending behavior through interactive dashboards and charts.

The application follows a structured dashboard layout including summary cards, analytics sections, filters, and transaction management. With Firebase authentication and cloud storage, each user gets a secure and personalized finance experience while enjoying a premium fintech UI design.

---

Deployement Link -> https://finance-tracker-ruby-six.vercel.app/


## 🚀 Key Features

🔐 Firebase Authentication (Login / Signup / Protected Routes)
💵 Add, edit, and delete income & expense transactions
📊 Dashboard with balance, income, and expense summary cards
📈 Advanced analytics with Pie, Bar, and Trend charts
🔎 Smart filters & search for transactions
🎨 Modern fintech UI using Tailwind CSS
⚡ Floating action button with modal-based forms
📱 Fully responsive design with smooth animations
🧠 Financial health score and insights cards
🌙 Light/Dark mode support
